Je nieuwe website draait via **Cloudflare**: snel, veilig en zonder server die onderhoud nodig heeft. Daarvoor moet je domeinnaam naar Cloudflare wijzen. Ik regel dit voor je, je hebt zelf geen Cloudflare-account nodig. Je domein blijft gewoon geregistreerd bij je huidige provider en je e-mail blijft werken.

## Wat ik van je nodig heb

Je hoeft zelf niets aan te maken. Ik heb alleen even toegang nodig tot het domeinbeheer bij je provider, bijvoorbeeld Mijndomein, TransIP of Cloud86 om de nameservers te wijzigen. Kies wat voor jou het makkelijkst is:

<Warning>
  Deel wachtwoorden nooit via gewone e-mail. Gebruik een wachtwoordmanager of een eenmalige deellink, en wijzig je wachtwoord na afloop.
</Warning>

## Wat ik daarna voor je doe

1. Ik zet je domein in Cloudflare en neem alle bestaande instellingen over, zoals je e-mail.
2. Ik controleer of alle e-mailinstellingen kloppen.
3. Ik zet **DNSSEC** uit bij je provider, als dat nodig is.
4. Ik wijzig de **nameservers** naar Cloudflare.
5. Zodra Cloudflare het domein heeft geactiveerd, test ik je website en e-mail.

De overstap is meestal binnen een paar uur actief, soms duurt het tot 24 uur. Ik laat je weten wanneer alles klaar is.
